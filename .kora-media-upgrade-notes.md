# Media upgrade references

- Expo MediaLibrary v54: https://docs.expo.dev/versions/v54.0.0/sdk/media-library/
  - Request granular `audio` permission with `getPermissionsAsync(false, ["audio"])` / `requestPermissionsAsync(false, ["audio"])`.
  - Paginate `getAssetsAsync` with `first`, `after`, `endCursor`, and `hasNextPage`.
  - Use `getAssetInfoAsync` for local asset information when URI access is platform-specific.
  - Config plugin supports `granularPermissions: ["audio"]`.
- Expo Audio v54: https://docs.expo.dev/versions/v54.0.0/sdk/audio/
  - `createAudioPlayer` instances must be removed when replaced/unmounted.
  - `expo-audio` does not reset finished playback automatically; seek to 0 before replay.
  - iOS standalone background playback requires `UIBackgroundModes: ["audio"]`.
- jsmediatags: https://github.com/aadsm/jsmediatags
  - React Native support uses `jsmediatags`, `buffer`, and `react-native-fs`.
  - Embedded `picture` data can be rendered as a `data:<format>;base64,...` URI.
  - Common shortcuts include `title`, `artist`, `album`, `picture`, and `lyrics`.
